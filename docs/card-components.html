Where to edit

css/card-library.css — shared dimensions, spacing, and media sizing for all four live variants.

css/liquid-glass-v6.css — existing glass material, title styles, status dots, and button treatments.

docs/card-components.html — this read-only preview. It imports the same CSS as the live app.

The live HTML/JavaScript builders are intentionally unchanged.
