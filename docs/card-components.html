Outside the regular card system: Featured trip titles remain 18px / 800, and Trips/Profile section headings remain 23px / 800. They are intentionally not controlled by the shared 16px card-title token.

Style guidance: Title = 16px / Bold 700 / 22px; Middle = 12px / Medium 500 / 16px; Bottom = 12px / Semi Bold 600 / 16px. Small action buttons and date-tile figures retain their distinct styles. Status dots and card layouts are unchanged.

Where to edit

css/liquid-glass-v6.css — existing glass material, title styles, status dots, and button treatments.

docs/card-components.html — this read-only preview. It imports the same CSS as the live app.
