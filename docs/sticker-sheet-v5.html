Yellow starts things. Ink shows where you are.

v5 fixes the weak selection states in v4. Selected controls now use an ink mark that passes 3:1 contrast: a bar, a ring, a dot or an underline. No control swaps between a filled and an unfilled version of itself. Yellow is only for primary actions and brand art. Tap anything, it’s live.

Colour

One brand hue, one state colour. Yellow never marks selection, because it is 1.6:1 on white. Ink does, at 16:1.
